## 🚀 Featured Projects

### ⚡ [SyncForge — Real-Time Collaborative Code Editor](https://github.com/kavyagrwl25/SyncForge)

A real-time collaborative code editor that enables multiple developers to edit a shared document simultaneously using **Yjs CRDTs and Socket.IO**.

**Key Features & Engineering Highlights**

- 🔄 Integrated **Yjs CRDTs** to support conflict-free concurrent editing and document convergence.
- ⚡ Implemented **incremental binary updates** through Socket.IO instead of full-document synchronization.
- 🧑‍💻 Connected **Monaco Editor with Y.Text** using `y-monaco` for bidirectional editing synchronization.
- 👥 Built isolated collaborative rooms with **active user presence, remote cursors, and language synchronization**.
- 🔁 Implemented **state-vector-based synchronization** for room joining and reconnection recovery.
- 🧪 Added automated integration tests covering concurrent editing, synchronization, reconnection, and room lifecycle management.

**Tech Stack:** `React.js` · `Node.js` · `Express.js` · `Socket.IO` · `Yjs` · `Monaco Editor` · `Tailwind CSS`

📂 **[Explore Repository](https://github.com/kavyagrwl25/SyncForge)**
